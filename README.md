# Modern Lockpicking (MWSE Lua)

MWSE Lua mod that introduces a Skyrim-like lockpicking system in The Elder Scrolls III: Morrowind.

## :link: Dependencies:

- [mwse](https://github.com/MWSE/MWSE)

## :white_check_mark: Features:

#### Visuals

- [x] Render lock mesh
- [x] Render knife mesh
- [x] Render lockpick mesh
- [x] Animate lock cylinder when rotating
- [x] Animate knife when rotating
- [x] Animate lockpick to look at mouse position
- [x] Animation upon entering lockpick mode
- [ ] Animation upon succesful lockpicking
- [ ] Animate lockpick jitter on wrong position

#### Gameplay

- [x] Unlock container/door upon succesful lockpicking
- [ ] Open container/door upon succesful lockpicking
